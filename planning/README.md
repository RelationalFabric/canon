# Planning

`planning/` holds Canon's planning material: the technology radar, the roadmap, methodology, and work that is still in progress. It is public and versioned. Permanent docs may link into it.

The root of this folder stays an explanation of the space. Transient work lives in subdirectories. `saga/` is the active saga for the branch. `rrs/` is for remediation records, and it is created only when a record exists. The patterns for both are in [process/](./process/).
